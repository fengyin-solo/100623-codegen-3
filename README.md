# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 消防器材与应急演练一体化清单（/fire）

独立于通用 CRUD 模块的领域功能，代码在 `frontend/src/fire/`（页面 `index.vue` +
`components/`，规则 `rules.ts`，事务状态 `store.ts`，老数据 `legacy-data.ts`）。

- **按区域多选、批量打理**：一次勾选多台、跨区域提交充装或报废；单据逐台给结果，
  没送成的单独成表并写明原因（已报废/待充装途中/不存在）。
- **重复提交**：每张单带幂等键，同一张单只有先落库的一版算数，后到的整套退回，
  只在首单上留痕；并发不同单据抢同一台时用实体版本号（CAS）判定，后到整笔拒绝。
- **演练排期看器材状态**：区域还有器材停在“待充装”时只能排到回厂之后；器材页与
  演练页共用 `rules.ts` 的同一份 `areaReadiness/drillBlockers`，并显示同源指纹。
  待办由当前器材状态实时推导；取消演练立即释放“区域+日期+时段”，可被后续班组占用。
- **季度整组另存**：按区域把演练与灭火器台账存成只读快照，页面条数与快照条数对账。
- **处理结论回写**：批量送充/报废结论回写现场巡视隐患清单，导出条数与页面一致。
- **规则换版**：v1 旧口径 / v2（GB 50444）切换后整体重算到期与等级，旧结论保留
  当时等级并注明版本，只在旁边给新版建议。
- **老数据迁移**：沿用原有编号；缺出厂日期按采购批次补齐（同批有已知日期取最早，
  整批缺失按验收日倒推 90 天，口径写在器材上）；两份取值冲突按统一依据仲裁
  （资产属性以台账为准、现场状态以最新巡视为准、业务状态以先落库单据为准）。
- **台账与业务清单一起变**：单据、器材台账、隐患、时段占用在同一事务提交，
  任一步失败整笔回滚。

迁移在首次打开时自动执行一次，报告在“规则版本·迁移·并发”页可查。
领域约束有一份可重复的 Node 冒烟脚本：`frontend/scripts/fire-smoke.ts`
（用 esbuild 打包后运行，50 项断言覆盖上述规则）。
